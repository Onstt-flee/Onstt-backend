# feedback-v0.4 독립 평가 결과

기준일: 2026-10-17

## 결론

`Qwen3-8B + feedback-v0.4 LoRA`는 같은 베이스 모델보다 크게 개선됐지만 봉인된
`holdout_v0.5`의 필수 기준 두 항목을 통과하지 못했다. 따라서 연구용 후보로만 보존하고
관리자 경고, 자동 학습 데이터 생성, 학습자 노출에는 사용하지 않는다.

시험지는 자동 생성·검증 120건이며 사람 또는 일본어 전문가 검수 결과가 아니다. 베이스라인과
LoRA는 사전 계획에 따라 같은 프롬프트와 생성 조건으로 각각 정확히 한 번 실행했다.

LoRA에서 맞은 문항은 72건, 반대 회귀는 4건이다.

## 실패 분석

계약 실패 4건은 모두 문법적으로 올바른 `来月は…に行きます。` 계열을
`false_negative`로 잘못 분류한 의미 모순이었다. 파서는 이 결과를 그대로 받아들이지 않고
계약 위반으로 차단했다.

- `FVH-05-014`, `FVH-05-069`: 원문과 같은 교정문에 임의 `tense_mismatch`를 부여
- `FVH-05-036`, `FVH-05-091`: `false_negative`인데 권장 decision을 `acceptable`로 생성

교정문 실패 6건은 모두 `…で…があります` 존재 장소 오류를 놓친 경우다.

- `FVH-05-004`, `026`, `059`, `081`, `092`, `103`

또한 음성 근거가 필요한 보류 문항 10건 중 1건을 불일치로 판단했다. 구문 계약의 fail-closed
검증은 잘 작동했지만 모델 자체의 존재 장소 일반화와 정상 문장 안정성이 아직 부족하다.

## 다음 판단

v0.5 holdout은 소비 완료됐으므로 재학습 선택이나 재평가에 다시 쓰지 않는다. 다음 모델을
만들 경우 먼저 새 미사용 holdout을 봉인하고, 정상 이동문 과민 반응과 존재 장소
`で → に` 누락만 최소대립쌍으로 보강해야 한다. 현재 v0.4를 우회 규칙으로 승인하거나
운영 피드백 worker에 연결하지 않는다.
