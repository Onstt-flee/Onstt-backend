# Qwen3-8B 베이스라인과 feedback-v0.3 LoRA 비교

기준일: 2026-10-17

## 결론

자동 생성·검증된 독립 `holdout_v0.4` 120건에서 Qwen3-8B BF16 베이스와
`feedback-verifier-v0.3` LoRA를 동일 프롬프트·생성 조건으로 비교했다. LoRA는 베이스보다
모든 핵심 품질 지표와 지연시간을 크게 개선했다.

따라서 현재 피드백 검수에는 베이스 단독이 아니라 `Qwen3-8B + feedback-verifier-v0.3`
조합을 유지하는 것이 타당하다. 다만 시험지가 자동 생성 자료이고 베이스 실행이 LoRA 공식
실행 뒤 추가된 후향적 비교이므로 운영 승인이나 전문가 품질 인증으로 해석하지 않는다.

## 실험 순서와 공정성 경계

1. holdout v0.4를 학습 데이터와 원문·완전 입력 중복 0건으로 봉인했다.
2. holdout을 읽지 않은 별도 1,782건으로 LoRA를 학습했다.
3. LoRA를 봉인 holdout에서 공식 1회 실행했다.
4. 이번에 누락됐던 Qwen3-8B 베이스라인을 같은 holdout에서 비교 전용으로 1회 실행했다.

베이스 가중치는 학습으로 변하지 않으므로 직접 모델 효과를 비교할 수 있지만, 시간 순서는
사전 베이스라인이 아닌 후향적 비교다. 실행기는 소비된 holdout에서 `baseline` 역할만
명시적으로 허용하며 LoRA 재실행과 재튜닝은 계속 차단한다.

## 동일 조건

- 베이스: Qwen3-8B BF16
- LoRA: Qwen3-8B BF16 + `feedback-verifier-v0.3`
- 시험지: holdout v0.4 120건
- temperature 0, top-p 1, max tokens 512
- vLLM 0.28.0, reasoning parser `qwen3`, FlashInfer sampler 비활성
- 시험지 SHA-256: `c22c5ddb0153c60d7087ef1e26580e669ea974e2bdafb0e65142f9eaeed60802`
