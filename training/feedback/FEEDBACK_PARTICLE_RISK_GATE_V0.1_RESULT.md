# 피드백 조사 위험 게이트 v0.1 후향 진단

기준일: 2026-10-18

## 결론

feedback-v0.4와 v0.5에서 반복된 존재 장소 `で` 및 목적지 `を行く` 실패를 대상으로,
기존 판단이나 피드백을 수정하지 않는 오프라인 위험 감지기를 구현했다. 게이트는 교정문이나
verdict를 생성하지 않고 `secondary_review_only` 신호만 반환한다.

소비 완료된 holdout v0.6에 후향 적용했을 때 원문상 조사 위험 50건을 모두 표시했고,
나머지 70건에는 신호를 만들지 않았다. v0.5의 조사 관련 실패 14건도 모두 신호 범위에
포함됐다. 이는 이미 결과를 확인한 시험지의 진단 결과이므로 모델 선택·운영 승인·정확도
주장에 사용하지 않는다.

## 안전 경계

- 기존 `judgment_results`와 `feedback_audits`를 변경하지 않는다.
- 모델 입력 계약 `feedback-v0.1`에 필드를 추가하지 않는다.
- 자동 교정문, verdict, 학습자 피드백을 생성하지 않는다.
- 신호가 있어도 오류로 확정하지 않고 별도 검토가 필요하다는 내부 메타데이터만 반환한다.
- 정상적인 행사 발생의 `で`와 경로 통과의 `を行く`는 명시적 예외로 fail-open한다.
- SudachiPy가 없는 현재 환경의 표면 패턴 구현이므로 미등록 의미 예외를 완전히 구분할 수 없다.

추가했다. 이 예외 목록은 완전한 일본어 의미 분석기가 아니므로 실제 운영 입력에서 독립
검증하기 전에는 worker 경로에 연결하지 않는다.
