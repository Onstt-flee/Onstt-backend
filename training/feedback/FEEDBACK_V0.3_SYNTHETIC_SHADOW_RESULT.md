# feedback-v0.3 합성 비노출 shadow 결과

실행일: 2026-10-15
범위: GPU BF16 판단모델 `v0.2-D` → GPU BF16 피드백모델 `v0.3`
판정: **운영 배선 검증 통과, 언어 품질 승인 아님**

## 목적과 제한

- 실제 저장 판단 결과가 아직 없으므로 결정론적으로 만든 일본어 입력 200건을 사용했다.
- 판단모델에는 `text`, `context`, `learner_level`만 전달했다.
- 피드백모델에는 위 입력과 판단 결과 네 필드만 전달했으며 판단 runtime, 모델명,
  adapter명, 양자화 형식, 생성 strata는 노출하지 않았다.
- 정답 라벨이 없는 검사이므로 정확도, 정밀도, 재현율, 과교정률을 계산하거나 주장하지 않는다.
- 실제 사용자 데이터, 오디오, 사용자 ID는 포함하지 않았다.

## 불일치 후보 1건

- 원문: `先生、ここは静かなです。`
- 판단모델: `acceptable`
- 피드백모델: `false_negative`, 권장문 `先生、ここは静かです。`

피드백모델이 누락 가능성을 잡아낸 예이지만, 권장 근거의 “명사 수식” 설명과
`modifier_connection` 분류는 재검토 여지가 있다. 사람 검수가 없는 합성 shadow 결과이므로
자동 학습 데이터나 품질 지표로 편입하지 않고 관리자 검토 후보로만 남긴다.

## 결론

비동기 dual-model 경로의 계약, source-blind 입력, 영속 queue, 별도 audit 저장,
원 판단 불변성은 합성 200건에서 정상 동작했다. 다음 실제 단계는 신규 판단 결과가
쌓인 뒤 동일 실행기를 이용해 GPU 판단 최소 200건의 비노출 shadow를 수행하는 것이다.
그 전까지 기능 플래그 기본 비활성, 학습자 노출 금지, 운영 승인 보류를 유지한다.
