# feedback-v0.5 독립 평가 결과

기준일: 2026-10-17

## 결론

`Qwen3-8B + feedback-v0.5 LoRA`는 베이스 모델보다 크게 개선됐지만, 봉인된
`holdout_v0.6`의 필수 기준 세 항목을 통과하지 못했다. 따라서 연구용 기록으로만 보존하고
관리자 경고, 자동 학습 데이터 생성, 학습자 노출에는 사용하지 않는다.

시험지는 자동 생성·검증 120건이며 사람 또는 일본어 전문가 검수 결과가 아니다. 베이스라인과
LoRA는 사전 계획에 따라 같은 프롬프트와 생성 조건으로 각각 정확히 한 번 실행했다. v0.6은
소비 완료로 잠갔으며 재평가나 v0.5 선택에 다시 사용하지 않는다.

## 실패 분석

계약 실패 2건(`FVH-06-085`, `086`)은 올바른 존재 문장을 잘못 교정 대상으로 분류하면서
권장 교정문은 원문과 같게 생성한 모순 사례다. 파서는 이를 저장 가능한
불일치로 보정하지 않고 계약 위반으로 차단했다.

권장 decision 실패는 14건이다.

- 존재 장소 `で → に` 오류를 정상으로 허용: 12건
- 목적지 `を → に` 오류를 `insufficient_evidence`로 잘못 보류: 2건

교정이 필요한 30건 중 정확한 최소 교정문은 16건(53.33%)이었다. 즉 v0.4의 실패 유형을
보강했지만 새로운 장소·명사 조합으로 충분히 일반화하지 못했다. 허위 불일치는 0건으로
안전성 한 축은 유지했으나, 오류 누락과 잘못된 보류가 많아 검수모델 역할에는 부족하다.

## 다음 판단

v0.5는 운영·staging 승인 후보가 아니다. 같은 자동 템플릿 계열을 계속 확대하는 추가 LoRA는
현재 실익이 낮으므로 여기서 중단한다. 다음 모델 후보를 만들기 전에 자동 생성 정답만으로
측정하기 어려운 문법 경계에 대해 최소 규모의 독립 검수 자료 또는 다른 생성·검증 원천을
확보해야 한다. 그 전까지 피드백 기능 플래그는 기본 OFF이고 기존 판단을 덮어쓰지 않는다.
