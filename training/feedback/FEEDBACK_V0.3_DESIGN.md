# feedback-verifier v0.3 설계 및 데이터 준비

기준일: 2026-10-15

## 목표

Qwen3-8B 기반 피드백 검수모델이 정상 일본어를 `일본어가 아닌 입력`으로 오인해
불일치를 만드는 문제를 줄인다. 판단모델 `judgment-v0.2-D`는 변경하지 않으며,
피드백 결과가 기존 판단을 덮어쓰지 않는 원칙도 유지한다.

## v0.2 실패에서 반영한 보강

- 완결된 정상 일본어 60개에 대해 올바른 `agree`와 잘못된
  `insufficient_evidence`를 한 쌍으로 제공했다.
- 보류가 필요한 미완성·잡음·타 언어 20개에 대해 올바른 보류와 잘못된 허용을
  대조했다.
- 조사·동사·형용사·수식 오류 20개에 대해 올바른 최소 교정과 오류 누락을
  대조했다.
- 소비된 holdout v0.3의 실패 문장 6개를 그대로 학습하지 않고 새 어휘와 문장으로
  일반화했다.

표시하지 않는다.

## 학습 이후 단일 평가 절차

이 절차는 2026-10-15 완료됐으며 결과는 `FEEDBACK_V0.3_HOLDOUT_V0.4_RESULT.md`에 고정했다.

1. v0.3 어댑터 파일·설정·학습 run manifest의 SHA-256을 기록한다.
2. `holdout_v0.4.protocol.json`에 어댑터 해시를 연결하고
   `ready_for_inference=true`로 전환한다.
3. temperature 0, top-p 1, max tokens 512로 120건을 정확히 한 번 실행한다.
4. 원시 결과는 Git 제외 경로에 보관하고 해시·점수·보고서만 추적한다.
5. 실행 즉시 `consumed=true`로 잠근다.

채택 기준은 계약 성공률 99% 이상, 허위 불일치율 2% 이하, 불일치 정밀도 95%
이상, 재현율 80% 이상, 권장 판단 정확도 90% 이상, 허용 교정문 일치율 80%
이상, GPU p95 5초 이하이다. 하나라도 실패하면 worker와 관리자 경고를 계속
비활성으로 유지한다.
