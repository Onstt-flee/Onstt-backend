## 결론과 다음 작업

1. v0.2-C의 개발셋 개선 일부는 **출력 계약만 바꾼 효과가 아니라 추가 학습 데이터가 동반된 효과**로 해석할 수 있다. 다만 독립 holdout에서 재확인 전에는 일반화 성능 향상으로 주장하지 않는다.
2. v0.2-D 후보 데이터는 공통 실패 6개 문항(JG-003·006·027·035·059·060)을 우선한다: 이동 경로 `を`, 보통체 유지, 존재 장소 조사, い형용사 과거형, 영어·한국어 보류. 정상·오류 최소대립쌍과 문맥을 함께 넣고 과교정 악화를 감시한다. JG-014와 같은 결정·교정문 충돌은 계약 검증 실패로 계속 노출한다.
3. 이미 확인한 150문항 holdout을 v0.2-D 학습이나 모델 선택에 사용하지 않는다. 설계·해시를 먼저 고정한 **새 미사용 시험지** 없이는 안전 기준 재검증이나 API 통합을 하지 않는다.
4. 상세 사람 검수 및 일본어 전문가 인증은 이 실험에 포함되지 않는다. `reason_ko`의 언어학적 타당성과 의미 보존은 자동 점수만으로 보장되지 않는다.
