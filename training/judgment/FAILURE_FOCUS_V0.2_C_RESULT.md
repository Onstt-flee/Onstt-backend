# Qwen3-4B 판단 LoRA v0.2-C 결과

상태: **운영 채택 보류**. 출력 위치를 백엔드 diff로 옮긴 계약 v0.2와 실패 집중 보강은 구현했지만, 신규 blind holdout에서 과교정·정밀도 안전 기준을 통과하지 못했다. FastAPI와 Swagger에는 연결하지 않는다.

## 변경 내용

- 모델 출력: `decision`, `corrected_text`, `error_types`, `reason_ko`만 생성
- 백엔드: 원문과 교정문을 Unicode 코드 포인트 기준으로 비교해 `start/end/source/replacement`를 결정론적으로 생성
- error type 수와 diff 수가 다르면 판단·교정문은 보존하고 `classification_review_required`로 표시
- 기존 v0.1 실행·결과는 보존
- v0.2-B 실패 11건을 대상으로 자동 검증된 88문항 추가
- 학습 조건: Qwen3-4B-Instruct-2507, seed 42, 45 step, 기존 v0.2-B와 동일

## 결론과 다음 조치

1. v0.2 출력 계약과 백엔드 edit 재구성은 유지한다.
2. 이 holdout 결과를 다시 학습 정답으로 사용하지 않는다.
3. v0.2-C 어댑터는 실험 체크포인트로만 보존한다.
4. 과교정 억제를 위한 더 다양한 정상 최소대립쌍과 복합 오류 학습 전략을 별도 v0.2-D에서 검토한다.
5. 안전 기준을 다시 통과하기 전에는 운영 API·Swagger 통합, Sudachi/RAG 관문, 평가모델 자동 재학습으로 확장하지 않는다.
