# 판단모델 v0.2-D 학습 데이터 생성 결과

상태: **데이터 생성·자동 검증 및 후속 45-step 학습·72문항 개발셋 비교 완료**. 기존 v0.2-C 628문항의 판단·교정문을 수정하지 않고, 개발셋 실패 유형을 겨냥한 120문항을 추가했다. 새 120문항은 `generated_validated`이며 사용자·일본어 전문가 검수본이 아니다. 비교 결과는 [C↔D 개발셋 비교](V0.2_D_DEV72_COMPARISON.md)를 따른다.

## 구성

| 구분 | 추가 120문항 | 결합 748문항 |
| --- | ---: | ---: |
| train / 내부 dev | 96 / 24 | 594 / 154 |
| 문법 허용 | 60 | 368 |
| 교정 필요 | 40 | 291 |
| 판단 불충분 | 20 | 89 |
| 복합 오류 | 10 | 35 |

정상 문장은 이동 경로 `を`, 보통체·필러 유지, 존재 장소 `に`, い형용사 과거형과 STT 표기 경계를 포함한다. 교정 문장은 목적지·존재 장소 조사, い형용사 과거형, 보통체 동사 활용과 두 오류를 함께 고치는 복합 문장이다. 영어·한국어 문장은 번역하지 않고 판단 불충분으로 남긴다. 정상/오류 최소대립쌍 16쌍은 같은 train 또는 dev 분할에 둔다.

## 격리·검증 결과

- 새 문항과 기존 개발셋 72문항, 이전 holdout 150문항, 새 미사용 holdout 120문항, 기존 학습 데이터 628문항, RAG JSON의 정규화 정확 중복: **0건**
- 기존 데이터셋과 문자 3-gram Jaccard ≥0.85 근접 중복: **0건**; 최대 0.75
- 원본 628문항은 결합 파일의 앞부분과 레코드 단위로 완전히 일치한다.
- 자동 테스트는 레코드 스키마, 분할·상태·해시, 정상/오류 대립쌍 분할, ChatML 정답 일치, 재생성 결정성과 두 holdout 비변경을 확인한다.
- holdout은 중복 검사에만 읽었다. 모델 응답·점수는 생성하거나 확인하지 않았다. 정확·근접 중복 0건이 언어학적 정답성이나 의미상 중복 부재까지 보장하지는 않는다.

## 다음 작업

별도 v0.2-D 어댑터 학습과 72문항 개발셋 비교를 완료했다. 조건·가중치 해시와 손실값은 [v0.2-D 학습 결과](V0.2_D_TRAIN_RESULT.md), 교정문 회귀는 [C↔D 개발셋 비교](V0.2_D_DEV72_COMPARISON.md)를 따른다. 다음에는 교정문 회귀 보강 여부를 결정하고 후보·프롬프트·채점 기준을 고정한다. 그 전에는 봉인한 새 120문항 시험지를 실행하지 않는다. 이전 150문항 holdout은 재사용하지 않으며, 안전 기준 통과 전에는 운영 API에 연결하지 않는다.
