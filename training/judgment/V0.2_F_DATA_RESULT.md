# 판단모델 v0.2-F 학습 데이터 생성 결과

상태: **데이터·ChatML·학습 설정 검증 완료, 학습 미실행**. 소비된 `holdout_v0.2`의 실패 유형만 범주로 사용했으며, 봉인된 `holdout_v0.3`은 중복 감사 외에는 사용하지 않았다.

보강 범위는 보통체·시제 보존, 이동 경로 `を`, い형용사 과거형, 1그룹 동사 정중형, 조사+활용 복합 오류, 외국어·미완성 발화의 올바른 보류다. 자동 생성분은 모두 `generated_validated`이며 사람 또는 일본어 전문가 검수로 표시하지 않는다.

기존 v0.2-E 828문항은 레코드 단위로 변경하지 않고 뒤에 120문항을 추가했다. 결합본은 948문항이며 train 744, dev 204다.

## 누수·중복 감사

- 대상: 72문항 개발셋, 기존 150문항 holdout, 소비된 holdout v0.2, 봉인된 holdout v0.3, v0.2-E 828문항, RAG JSON
- 정규화 정확 중복: 0건
- 문자 3-gram Jaccard 0.85 이상 근접 중복: 0건
- 관측 최대 Jaccard: 0.7692
- 한계: 문자열 감사는 의미상 패러프레이즈나 베이스 모델 사전학습 중복을 배제하지 못한다.

`holdout_v0.3`은 SHA-256 `cb37c594d40478057ab65d98fff6dcaf7889db9fd799dc3ee414a455ff5cde4f` 그대로 유지했고 모델 추론을 실행하지 않았다.

## 학습 전 검증

LoRA 환경에서 `--validate-only`를 실행해 train 744, dev 204, 출력 계약 `judgment-v0.2`, 원본 데이터 해시 및 `user_reviewed`/`generated_validated` 상태를 확인했다. 설정은 실험 경로를 제외하고 v0.2-E와 동일한 Qwen3-4B, seed 42, 45-step 조건이다.

다음 단계는 별도 v0.2-F 어댑터를 45-step 학습한 뒤, 봉인된 시험지를 열지 않고 기존 72문항 개발셋에서 회귀와 실패 유형을 확인하는 것이다.
