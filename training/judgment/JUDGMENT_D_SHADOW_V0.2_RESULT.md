# v0.2-D 비중복 100건 shadow 파일럿 결과

## 결론

- 실행일: `2026-10-06` (UTC)
- 모델: `Qwen3-4B + judgment-v0.2-D LoRA`
- 전략: D 단독 + 비교정 원문 보존 위반에 한한 1회 재시도
- 상태: **제한적 staging/shadow 기준 통과, 운영 기본값·학습자 노출은 미승인**

기존 공식 50건 입력 snapshot을 인증·제외한 실제 저장 STT 100건에서 최종 출력 계약 성공은 `99/100`, 재시도율은 `1/100`, 성공 99건 기준 p95 지연시간은 `1108.711ms`였다. 사전 기준을 모두 충족했다. 다만 원문 보존 위반 1건은 재시도 후에도 같은 계약 위반을 반복해 최종 503 대상으로 남았다. 재시도가 이번 표본의 성공률을 높인 것은 아니다.

정답 라벨과 오디오가 없는 운영 shadow이므로 문법 정확도, 과교정률, 발음 오류 또는 STT 오류를 평가한 결과가 아니다.

## 안전한 재시도 정책

- `acceptable` 또는 `insufficient_evidence`인데 `corrected_text`가 원문과 다를 때만 한 번 재호출한다.
- 재시도 프롬프트는 원문 보존 계약만 다시 강조하며 입력·모델·어댑터·온도·토큰 한도는 유지한다.
- 잘못된 JSON, 전송 오류, 타임아웃, 빈 입력은 자동 재시도하지 않는다.
- 재시도도 실패하면 HTTP 503으로 차단하고 DB에 저장하지 않는다.
- 백엔드가 모델의 `corrected_text`를 원문으로 몰래 덮어쓰지 않는다.
- 공개 API 응답과 `judgment_results` 스키마는 변경하지 않는다. 시도 횟수와 최초 오류는 shadow 원시 파일과 집계에만 기록한다.

## 실패와 무결성

최종 실패 1건은 첫 시도와 재시도 모두 `Non-correction decisions must preserve input text`였다. 서비스는 결과를 수정하거나 보류 판단으로 위장하지 않고 실패 처리했다. 공식 100건 결과는 실패 확인 후 재실행하지 않았다.

## 결정

1. v0.2-D는 기능 플래그 기본 비활성 상태의 제한적 staging/shadow 후보로 유지한다.
2. 이번 기준 통과만으로 운영 기본값을 활성화하거나 학습자에게 자동 교정을 확정 제공하지 않는다.
3. 재시도는 안전한 차단을 유지했지만 성공률 개선은 0건이므로 추가 재시도나 백엔드 자동 복원으로 확대하지 않는다.
4. `holdout_v0.4`는 모델 추론 0회 상태로 보존한다.
5. boundary gate adversarial 확대, 재학습, SudachiPy/ChromaDB, 평가모델은 후순위로 유지한다.
6. 다음 필수 단계는 라벨과 오디오 근거가 분리된 최소 독립 품질 검수 표본을 정의하는 것이다. 그 전에는 shadow 범위를 넘는 승격을 하지 않는다.
