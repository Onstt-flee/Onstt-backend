# 판단모델 v0.2-H 고정 노출 샘플링 실험 설계

상태: **실험 완료, 개발 기준 실패, holdout v0.4 미사용**. v0.2-G는 문항 수를 늘렸지만 D보다 구조·과교정·판단·교정문이 모두 후퇴했다. H는 새 정답을 더 만들지 않고 같은 v0.2-G 소스의 노출 빈도만 바꿔 샘플링 효과를 분리했다. 최종 수치와 결정은 [v0.2-H 결과](V0.2_H_TRAIN_AND_DEV72_RESULT.md)를 따른다.

## 사전 봉인 시험지

- 파일: `evaluation/judgment/holdout_v0.4.jsonl`
- 문항: 120개(정상 50, 교정 50, 보류 20, 복합 오류 10)
- SHA-256: `904ca090ccd0e209f95fa68a6a3e9fd762a0009c802f7eae7670838f9558221e`
- 상태: `generated_validated`; 사람·일본어 전문가 검수본이 아님
- 기존 평가·학습·RAG 정규화 정확 중복: 0
- 문자 3-gram Jaccard 0.85 이상: 0, 관측 최대 0.75
- 모델 추론 횟수: 0

시험지는 H 데이터·학습·채택 기준과 실행 protocol을 모두 고정하기 전에는 모델에 노출하지 않는다. 라벨은 학습·프롬프트·후보 선택에 사용하지 않는다.

## H에서 바꾸는 것

v0.2-G train 675개를 그대로 한 번 학습하면 45 step × accumulation 16 = 720 microbatch이므로 첫 epoch 675개 뒤 다음 shuffle의 45개가 우연히 한 번 더 노출된다. H는 이 45개를 명시적으로 고정한다.

- D 기반 train 594개: 각각 1회
- G train 81개: 각각 1회
- G train `insufficient_evidence` 24개: 추가 1회
- G train `acceptable` canonical 앞 21개: 추가 1회
- 총 720개 노출, 고유 입력 675개
- 교정 예시 추가 반복: 0

따라서 G와 의미 정답·모델·seed·45-step·학습률·LoRA 설정은 같고, 변경 변수는 45개 추가 노출의 구성뿐이다. 실제 shadow 원문, 소비된 holdout, 모델 출력은 사용하지 않는다.

## 개발셋 사전 판정 기준

기존 72문항은 반복 사용된 개발 진단셋이므로 최종 성능 증명이 아니다. H는 다음 조건을 모두 만족할 때만 v0.4 실행 후보가 된다.

1. JSON/구조 72/72
2. 과교정 0/33
3. 판단 정확도 D의 69/72 이상
4. 올바른 보류 D의 11/12 이상
5. 허용 교정문 D의 19/27 이상
6. 복합 오류 완전 교정이 D보다 감소하지 않음

하나라도 실패하면 H를 미채택하고 holdout v0.4를 소비하지 않는다.
