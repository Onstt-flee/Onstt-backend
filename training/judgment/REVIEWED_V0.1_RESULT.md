# Qwen3-4B 판단 LoRA reviewed v0.1 결과

기준일: 2026-09-14  
상태: **학습·72문항 평가 완료, 운영 기준 미통과**

## 결론

익명 사용자 검수 완료 300문항으로 Qwen3-4B LoRA를 새로 학습했다. provisional LoRA보다 엄격 계약과 올바른 보류는 개선됐지만, 원시 판단 정확도와 과교정은 악화됐다. 따라서 reviewed 어댑터도 운영 API나 Swagger에 연결하지 않는다.

검수 완료본은 데이터 기준으로 유지한다. 다만 검수자의 상세 근거를 그대로 `reason_ko` 학습 목표로 사용한 설계는 다음 버전에서 분리해야 한다. 이번 비교에서 판단은 1건, 교정문은 2건만 바뀌었지만 `reason_ko`는 300건 전부 바뀌어, 라벨 수정 효과와 설명문 변화 효과를 분리할 수 없었다.

## 데이터 변화 해석

provisional 원본과 reviewed 학습 목표의 차이는 다음과 같다.

| 변경 필드 | 문항 수 |
| --- | ---: |
| `reason_ko` | 300 |
| 허용 교정 후보 | 12 |
| `corrected_text` / edits | 2 |
| decision | 1 |

평균 근거 길이는 24.2자에서 31.4자로 늘었다. 이 실험만으로 설명문 길이가 성능 악화의 원인이라고 확정할 수는 없지만, 가장 큰 교란 변수다. 낮아진 dev loss도 독립 72문항 일반화 향상을 보장하지 않았다.

## 다음 실험 조건

1. 사람의 상세 근거는 검수 감사 자료로 보존하되, 학습용 `reason_ko`는 짧고 일관된 형식으로 별도 생성한다.
2. reviewed decision과 최소 교정문은 그대로 유지한다.
3. `公園を歩く`, 필러, 캐주얼 문체, STT 표기 경계 등 과교정 8건에 대응하는 정상 음성 예를 보강한다.
4. 모델 출력에서는 edit 위치를 제외하고 백엔드가 `corrected_text` 차이로 계산한다.
5. 다음 재학습은 이유 설명 형식만 통제한 ablation으로 진행해 원인을 분리한다.
6. 과교정과 엄격 계약 목표를 통과하기 전 운영 통합을 보류한다.
