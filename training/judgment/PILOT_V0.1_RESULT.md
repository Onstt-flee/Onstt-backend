# Qwen3-4B 판단 LoRA 파일럿 v0.1 결과

기준일: 2026-09-14  
상태: **실험용 provisional 데이터 결과 — 운영·전문가 승인 아님**

## 결론

Qwen3-4B에 300개 임시 합성 문항으로 LoRA를 적용하자 문법 판단과 교정문 내용은 베이스보다 개선됐다. 그러나 정상 문장을 고치는 과교정이 늘었고, 모델이 직접 생성한 Unicode edit 위치 오류 때문에 엄격 JSON 계약 성공률은 오히려 낮아졌다. 따라서 이 어댑터를 운영에 연결하거나 같은 데이터로 추가 학습하지 않는다.

다음 실험은 사람 검수 후 데이터를 보완하고, 모델은 `decision`·`corrected_text`·오류 유형·근거를 생성하며 edit 위치는 백엔드가 결정론적으로 계산하는 오프라인 계약 v0.2를 먼저 검증한다. 현재 운영 계약은 변경하지 않는다.

## 오프라인 edit 재구성 v0.2 결과

동일한 원시 72개 응답에서 `corrected_text`의 문자열 차이를 Python Unicode 코드 포인트 기준 edit로 재구성했다. 원래 엄격 계약 37/72에서 **67/72**로 30건 회복됐다. 남은 5건은 잘못된 내용 또는 오류 유형 매핑 자체의 모순이므로 위치 계산만으로 숨기지 않았다.

- `JG-049`, `JG-058`: 비교정 판단인데 원문을 바꿈.
- `JG-060`: 교정 판단인데 교정문이 원문과 같음.
- `JG-019`, `JG-047`: 교정 내용과 모델 오류 유형 개수/범위가 일치하지 않음.

이 결과는 edit 위치를 LLM이 직접 생성할 이유가 약하다는 구조적 근거다. 다만 67건의 내용이 모두 옳다는 뜻은 아니며, 원시 과교정 7건은 그대로 남는다. 재현 결과는 `evaluation/judgment/results/qwen3-4b-judgment-pilot-v0.1-offset-reconstruction.json`에 기록했다.
